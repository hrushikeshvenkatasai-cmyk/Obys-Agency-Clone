Obys Agency – Fully Animated Website Clone

A modern, high-animation Obys Agency inspired website clone built using
HTML5, CSS3, JavaScript (ES6), GSAP, and Locomotive Scroll.
This project focuses on delivering a premium, smooth, and immersive UX with advanced
scroll interactions, custom loaders, text animations, parallax effects, and responsive layouts.

🎯 Features
🔹 Smooth Scroll Experience

Implemented using Locomotive Scroll to create a fluid, modern scrolling effect.

🔹 GSAP Animations

Text reveal animations

Image transitions

Section-based scroll animations

Micro-interactions

🔹 Interactive Hover Effects

Dynamic hover animations for images and text to replicate the Obys motion style.

🔹 Custom Loader Animation

A fully animated page loader that sets a polished user experience from the start.

🔹 Modern Layout & Typography

Styled with clean, minimal design principles inspired by the real Obys website.

🔹 Fully Responsive

Responsive layouts optimized for desktop and mobile devices.
